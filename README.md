# Informe del Proyecto 1 - Computacion Paralela y Distribuida

Informe del proyecto de paralelizacion con OpenMP de un protector de pantalla
estilo Minecraft. Universidad del Valle de Guatemala, semestre 2 de 2026.

El codigo fuente del programa vive en un repositorio aparte
(https://github.com/DerNait/minecraft-screen-saver). Aqui solo esta el
documento del informe y el material que lo acompana.

## Contenido

| Ruta | Que contiene |
| --- | --- |
| `Informe - Proyecto 1 Computacion Paralela.docx` | El informe completo con sus anexos |
| `anexos/` | Diagramas y figuras que usa el informe |
| `generar_informe.py` | Script que arma el .docx con python-docx |

El documento sigue la convencion de formato del curso, o sea Times New Roman en
todo, cuerpo de 11 pt, interlineado 1.15, margenes de una pulgada y los pies de
tabla y figura debajo del elemento.

Para regenerarlo hace falta python-docx.

```
pip install python-docx
python generar_informe.py
```

El indice se arma con un campo de Word. Al abrir el documento hay que
seleccionar la linea del indice y presionar F9 para que se llene.
